# Car Price Prediction 🚗

A machine learning project to predict car prices using regression algorithms. This project demonstrates data analysis, preprocessing, and model building using Python data science libraries.

## 📊 Project Overview
This project uses various Python libraries to analyze vehicle data, clean raw data, and build predictive models to estimate car prices based on multiple features.

## 🛠️ Technologies Used
- **Python 3**
- **NumPy** - Numerical computations
- **Pandas** - Data manipulation and analysis
- **Matplotlib & Seaborn** - Data visualization
- **Scikit-learn** - Machine learning models
- **Jupyter Notebook** - Interactive development

## 📁 Dataset
- Contains features like make, model, year, mileage, condition, etc.
- Includes data cleaning and preprocessing steps

## 🎯 Key Features
- Exploratory Data Analysis (EDA)
- Data cleaning and feature engineering
- Multiple regression models comparison
- Performance evaluation metrics
- Model predictions on new data

## 📈 Results
- Model comparison and selection
- Prediction accuracy metrics
- Visualization of actual vs predicted prices

## 🚀 How to Use
1. Clone the repository
2. Install required libraries: `pip install numpy pandas matplotlib seaborn scikit-learn`
3. Open the Jupyter notebook
4. Run cells to see analysis and predictions
